# Archery Game

## Overview

Archery Game is a simple browser-based shooting game built using HTML, CSS, and JavaScript. The project allows the player to aim and shoot arrows toward a target using interactive frontend game logic.

This project was created to practice JavaScript event handling, DOM manipulation, game mechanics, image positioning, and frontend styling.

## Features

- Browser-based archery shooting game
- Interactive arrow movement
- Bow and arrow graphics
- Shooting target image
- Background image-based game scene
- JavaScript-based game mechanics
- HTML and CSS layout
- Works directly in the browser

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The game will open directly in your browser.

No installation is required.
